# 文档地图

> 状态: 稳定 | 更新: 2026-08-16

## 文档维护规则

1. **代码先行**：代码是唯一事实来源，文档描述代码。发现文档与代码不一致时，改文档。
2. **变更绑定**：改代码时，同时检查"文档矩阵"的变更触发点列，命中即同步更新。
3. **决策记录**：任何影响架构的决策（线程模型、模块边界、布局策略、依赖选型），先写/更新 ADR，再写代码。格式见 [decisions/README.md](decisions/README.md)。
4. **元信息**：每份文档首部必须保留状态/更新日期块。更新内容后必须刷新日期。
5. **不重复**：AGENTS.md 只放速查与规范，详细内容一律链接到 docs/。同一知识点不要在两份文档重复展开。
