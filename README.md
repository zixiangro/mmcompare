# MMCompare

轻量级图片对比桌面工具：多图查看、选择框亮度对比、双文件夹对比、EXIF / 直方图分析。

基于 [egui](https://github.com/emilk/egui)（原生 GUI，无浏览器依赖），支持 Windows / macOS / Linux。

## 功能一览

| 功能 | 说明 |
|---|---|
| 多图查看 | 1-8 张图片网格布局，支持缩放、平移、重排、删除 |
| 局部对比 | 按 `P` 进入局部模式，拖拽框选同步区域，实时对比各图 RGB 均值 |
| 双文件夹对比 | 拖入两个文件夹，各打开一张图片，`Space`/`B` 同步索引逐张对比 |
| 文件夹浏览 | 文件夹 cell 列表/缩略图双视图，多选、滚动、右键菜单 |
| EXIF 摘要 | 按 `E` 显示图片名称 + 相机参数（型号/镜头/光圈/快门/ISO/闪光灯） |
| 直方图 | 按 `H` 显示 Y 亮度直方图 |
| 旋转 | 数字键 `1-8` 顺时针旋转对应图片 |
| 加载反馈 | 后台线程解码，加载进度与失败列表横幅提示，不卡界面 |

## 快速开始

```bash
# 运行（需 Rust 工具链）
cargo run --release

# 启动时直接打开图片或文件夹
cargo run --release -- photo1.jpg photo2.png my_folder
```

或拖拽：打开应用后，把图片文件 / 文件夹直接拖进窗口。

## 使用说明

### 两种模式（互斥）

应用分**文件模式**与**文件夹模式**，拖入目录即进入文件夹模式，之后拖入文件会被忽略（反之亦然）。清空所有内容后可重新选择模式。

### 图片模式

| 操作 | 效果 |
|---|---|
| 拖入图片（≤8 张） | 网格排列，按文件名排序 |
| 滚轮 | 全局缩放（缩放 ≥1 时生效） |
| 左键拖拽 | 缩放 >1 时全局平移 |
| 右键拖拽 | 单张图片平移 |
| `Ctrl` + 左键拖拽 | 拖到目标格子重排 |
| `Ctrl` + 右键 | 删除图片 |
| `1`-`8` | 旋转对应位置图片（顺时针 90°） |
| `Q`（按住） | 两张图时互换显示（快速对比；文件夹对比对同样可用） |

### 局部模式（按 `P` 切换）

- 左键拖拽框选：选择框在**所有图片上同步**（同一归一化区域），松手后每张图左上角显示该区域的 RGB 均值标签（Luma / R:G / B:G / 饱和度）
- 右键拖拽：移动已有选择框
- 再按 `P` 退出并清空选区
- `E` / `H` 可叠加显示 EXIF / 直方图

### 文件夹模式

| 操作 | 效果 |
|---|---|
| 拖入文件夹 | 文件夹 cell 入网格（列表视图，按文件名排序） |
| 单击条目 | 选中（`Ctrl` 多选、`Shift` 范围选） |
| 双击条目 | 打开为图片（单文件夹可开多张；多文件夹时每文件夹限 1 张，重复打开自动替换） |
| 右键菜单 | 打开图片 / 在资源管理器中定位 / 从列表移除 / 打开选中 / 切换列表·缩略图视图 |
| 滚轮 | 滚动条目列表 / 缩略图网格 |

**对比流程**（双文件夹）：
1. 拖入文件夹 A、B（并列展示）
2. 各双击打开一张图片 → 两张图并排，文件夹隐藏
3. `Space` / `B` → 两个文件夹**同步**前进/后退到下一张（各自索引）
4. `Esc` → 关闭图片，回到文件夹视图
5. 对比对状态下 `Ctrl`+右键删除被禁用（防误删），用 `Esc` 退出

**单文件夹多图**：可同时打开多张；此时 `Space`/`B` 不响应导航（索引有歧义），删到每文件夹 1 张即恢复。

### 其他

- 窗口标题显示当前模式（如 `MMCompare - EP` = EXIF + 局部模式）
- 缩略图：JPEG 走解码器级降采样（快且省内存），每文件夹最多生成 200 张，超限条目显示占位
- 加载失败的文件在顶部横幅列出，可重新拖入重试

## 常见问题

**拖入文件没有反应？**
检查是否处于文件夹模式（先拖过文件夹）。两种模式互斥，清空所有格子后可重新选择。

**对比时怎么删除一张图？**
对比对（两个文件夹各开一张）禁删——按 `Esc` 退出对比，回到文件夹视图后再管理。

**大文件夹会不会卡？**
不会。目录扫描与缩略图生成全部在后台线程分批执行（每批 8 张），界面始终可操作；缩略图生成与打开图片互不阻塞。

**图片内存占用？**
全分辨率 RGBA 常驻内存（选区统计与旋转需要）：8 张 50MP 图约 1.6GB，属已知取舍。
