# mmcompare

图片查看 / 对比工具，基于 [egui](https://github.com/emilk/egui) 的桌面应用。

## 运行

```powershell
cargo run
```

## 功能

- **多图查看**：1-8 张图片同时显示，自适应网格布局
- **拖拽打开**：从资源管理器拖拽图片到窗口（加载中拖拽不丢失）
- **并行加载**：解码、EXIF 解析、直方图计算都在后台线程执行，主线程只做纹理上传
- **缩放 / 平移**：滚轮全局缩放，左键全局平移，右键单图平移
- **局部模式**：按 `P` 框选区域，归一化坐标同步到所有图片，显示 RGB 均值 / 亮度对比
- **EXIF 摘要**：按 `E` 显示相机、镜头、光圈、快门、ISO、闪光灯信息
- **直方图**：按 `H` 显示每张图的 Y 亮度直方图
- **旋转**：按 `1-8` 旋转对应位置图片（顺时针 90°）
- **双图对比**：两张图时按住 `Q` 互换显示
- **Ctrl 管理**：`Ctrl`+右键删除图片、`Ctrl`+左键拖拽重排

## 布局

| 数量 | 排列 |
|---|---|
| 1-3 | 单行等宽 |
| 4 | 2 × 2 |
| 5 | 首行 3 + 次行 2 |
| 6 | 首行 3 + 次行 3 |
| 7 | 首行 4 + 次行 3 |
| 8 | 首行 4 + 次行 4 |

## 技术栈

eframe 0.35 + egui 0.35 (wgpu) · `image` 0.25 · `nom-exif` 3.6 · `env_logger` + `log`
